# Capture to brain

The vault is the user's only persistent memory — anything durable that isn't written there is lost when the session ends. An X/Twitter URL or tweet id takes the tweet branch: read [`TWEET.md`](TWEET.md) and follow it instead of the steps below.

1. Distill the durable thing — the rule or decision and its why, stated timelessly, not the conversation that produced it.
2. Write it to the vault: read `~/brain/AGENTS.md` first and follow it in full (note type, template, draft-only authorship, wikilinks).
3. Close by saying what was written — the filename(s), and that each note sits as `status: draft` in the vault's Review queue.
